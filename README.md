# Madlibs Game

A fun, military-themed Mad Libs story generator built in Python. Perfect for USMC veterans, families, or anyone who enjoys creative storytelling with a boot camp twist!

## Features
- 🎖️ Interactive prompts for a military-themed adventure story
- Simple and easy to run (no dependencies)
- Replayable for endless fun
- Customizable inputs (bases, ranks, adjectives, etc.)

## Quick Start

1. Clone the repo:
   ```bash
   git clone https://github.com/jeffmac007/Madlibs.git
   cd Madlibs
   ```

2. Run the game:
   ```bash
   python Madlib.py
   ```

3. Fill in the prompts and enjoy your custom story!

## Sample Output
```
At Camp Pendleton, a brave Sergeant led a mission with their platoon. 
They faced charging challenges and triumphed under the stars sky. 
It was a truly heroic day for the Corps!
```

## How It Works
The script uses Python's `input()` and f-strings to fill a fun military story template.
